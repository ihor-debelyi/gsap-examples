## About This Collection

This repository serves as an educational reference collection of GSAP animations. Each project demonstrates specific animation techniques and patterns that can be adapted for production use.

## Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Running a Project

```bash
# Navigate to any project directory
cd [project-name]

# Install dependencies
npm install

# Start development server
npm run dev
```

The development server will typically start at `http://localhost:3000` (Next.js) or `http://localhost:5173` (Vite).
